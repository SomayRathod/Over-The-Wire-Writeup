# OverTheWire Writeups

This repository contains my writeups and notes for challenges from **OverTheWire**, mainly focusing on **Bandit**.

The goal of these writeups is not just to document the solutions, but to explain the commands and techniques I learned while solving each level.

## Writeup Format

Each writeup generally follows this structure:

* **Problem Description**: What the challenge asks
* **Solution**: The approach used to solve it
* **Commands Learned**: Important commands and commonly used options
* **Takeaways**: What I learned from the challenge

The focus is on understanding **why** a command or technique is used rather than simply copying the solution.
